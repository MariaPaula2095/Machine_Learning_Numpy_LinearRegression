Types of Machine Learning

Exploring the core paradigms and practical real-world applications

USED IN THIS APP
Supervised Learning
Labeled Data ($X \rightarrow Y$)

The model is trained using a labeled dataset where every input is explicitly mapped to a target output. It learns mapping functions to make accurate predictions or classifications.

Real Example:

Email spam filtering or predicting crop yield based on fertilizer input.

Try Supervised Model Demo
Unsupervised Learning
Unlabeled Data

The model analyzes unlabeled data without predefined targets. It discovers hidden patterns, clusters, structural relationships, and underlying distributions within the dataset.

Real Example:

E-commerce customer segmentation grouping users by purchasing behaviors.

Semi-Supervised Learning
Hybrid Dataset

Combines a small volume of labeled data with a large amount of unlabeled data during training, reducing manual annotation costs while preserving high accuracy.

Real Example:

Medical image diagnosis using a few doctor-annotated scans alongside thousands of unannotated scans.

Reinforcement Learning
Rewards & Penalties

An autonomous agent learns optimal sequential actions by interacting with an environment through continuous trial and error, earning positive rewards or penalties.

Real Example:

Autonomous vehicle steering software maximizing safety rewards in driving simulations.

Types of Machine Learning

← Back to ML Overview
  • Supervised Learning

    Definition: The model is trained using a labeled dataset, where every input is explicitly mapped to a target output. It learns mathematical mapping functions to make accurate predictions or classifications on new, unseen data.

    Example: Email spam filtering, where the system classifies emails as "Spam" or "Not Spam" based on previously labeled historical messages.

  • Unsupervised Learning

    Definition: The model analyzes unlabeled data without human guidance or predefined targets. It discovers hidden structures, relationships, groupings, and underlying distributions within the dataset on its own.

    Example: Customer segmentation in e-commerce, where the algorithm automatically groups users into distinct buyer personas based on purchasing behaviors.

  • Semi-Supervised Learning

    Definition: A hybrid technique that combines a small amount of labeled data with a large volume of unlabeled data during training. It reduces manual labeling effort and costs while maintaining high predictive accuracy.

    Example: Medical image diagnosis, training a diagnostic system using a few doctor-labeled X-rays alongside thousands of unannotated medical scans.

  • Reinforcement Learning

    Definition: An autonomous agent learns to make optimal sequential decisions within an environment. It improves through continuous trial and error, earning positive rewards for correct actions and penalties for mistakes.

    Example: Autonomous vehicle control, where self-driving software learns to steer, accelerate, and brake safely by maximizing safety rewards during simulations.

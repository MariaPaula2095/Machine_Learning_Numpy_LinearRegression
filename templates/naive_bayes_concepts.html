Naive Bayes Concepts

Theoretical foundation of probabilistic classification using Bayes' Theorem.

1. Definition & Justification

Naive Bayes is a supervised probabilistic classifier based on Bayes' Theorem, with the "naive" assumption that features are conditionally independent given the class. Despite this simplification, it performs remarkably well on many real-world classification tasks and is fast to train.

2. Problem Variables (Domain Definition)
(X) Independent Variable: PageValues — Continuous numerical feature representing the value assigned to a web page based on how often users who visit it end up purchasing.
(Y) Target Variable (Binary): Purchase Decision (Revenue) — Binary categorical outcome ($1 = \text{Yes}$, $0 = \text{No}$) predicting user conversion.
3. Bayes' Theorem

Naive Bayes calculates the posterior probability of a class $y$ given evidence (feature) $x$ using:

$$P(y \mid x) = \frac{P(x \mid y) \, P(y)}{P(x)}$$

Since this project uses a continuous feature (PageValues), a Gaussian Naive Bayes variant is used, which assumes $P(x \mid y)$ follows a normal distribution for each class. The class with the highest posterior probability is chosen as the prediction.

4. Logistic Regression vs Naive Bayes
Feature Logistic Regression Naive Bayes
Approach Discriminative (models decision boundary directly) Generative (models probability distribution per class)
Key Assumption Linear relationship between features and log-odds Conditional independence between features
Training Speed Moderate (iterative optimization) Very fast (closed-form probability estimates)
Output Probability via Sigmoid function Probability via Bayes' Theorem

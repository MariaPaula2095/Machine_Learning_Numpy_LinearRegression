Reinforcement Learning

Reinforcement Learning: Concepts

How an agent learns by trial and error: from rewards and policies to Epsilon-Greedy and Q-Learning, applied to a 10 × 10 grid navigation exercise.

1. What is Reinforcement Learning?

Reinforcement Learning (RL) is a branch of machine learning in which an agent learns to make decisions by interacting with an environment. There is no labeled dataset: the agent tries actions, receives rewards or penalties as feedback, and gradually learns which behavior maximizes the cumulative reward.

Supervised

Learns from labeled examples (input → known answer).

Unsupervised

Finds hidden structure in unlabeled data.

Reinforcement

Learns from rewards obtained by acting in an environment.

2. The Agent–Environment Loop

Learning happens through a continuous cycle: the agent observes the current state, chooses an action, and the environment answers with a new state and a reward.

3. Core Elements
Agent

The learner and decision maker that observes the state and selects actions.

In the exercise: the piece that starts at cell A and moves through the grid.
Environment

Everything the agent interacts with. It applies the rules and returns feedback.

In the exercise: the 10 × 10 grid with walls, danger zones and a target.
State (s)

A description of the current situation of the agent in the environment.

In the exercise: the agent's current cell (row, column).
Action (a)

A move the agent can choose in a given state.

In the exercise: Up, Down, Left or Right.
Reward (r)

A numeric signal that tells the agent how good its last action was.

In the exercise: a positive value for reaching T.
Penalty

A negative reward that discourages undesirable behavior.

In the exercise: entering a danger zone D (and, depending on the design, wasting steps).

5. How the Agent Learns

The strategy of the agent: a rule that maps each state to the action to take. Learning means improving the policy until it leads to the highest cumulative reward.
In the exercise: the final policy picks, for every cell, the direction with the best Q-value, which produces the learned path from A to T.

One interaction cycle: the agent observes a state, takes an action, and receives the next state and a reward.
In the exercise: each move to a neighboring cell is one step.

A complete sequence of steps from a start state until a terminal condition is reached.
In the exercise: an episode starts at A and ends when the agent reaches T or the maximum number of steps is exhausted.

The information collected in each step, usually stored as a tuple (s, a, r, s'): state, action, reward and next state. The agent learns from these transitions.
In the exercise: (current cell, direction, reward, next cell).

Exploration means trying random or less-known actions to discover new information. Exploitation means choosing the action that currently looks best. Too much exploration wastes time; too much exploitation can trap the agent in a mediocre route.
In the exercise: early on the agent wanders and may hit danger zones; later it mostly follows the best-known route.

A strategy to balance exploration and exploitation: with probability ε the agent picks a random action, and with probability 1 − ε it picks the action with the highest Q-value. ε starts high and decays after each episode down to a minimum value.
ε ← max(εmin, ε × decay)

The reward r received right after taking an action. It only measures the short-term outcome of that single step.
In the exercise: the value obtained when moving into an o, D or T cell.

The total (discounted) reward accumulated from a given step until the end of the episode. The agent aims to maximize the return, not just the immediate reward.
Gt = rt+1 + γrt+2 + γ²rt+3 + ...

A number between 0 and 1 that controls how much future rewards matter. Close to 0, the agent is short-sighted; close to 1, it values long-term rewards almost as much as immediate ones.
In the exercise: a high γ lets the reward at T "travel back" to the cells far from the target.

The expected return when starting from state s and following the policy afterwards. It answers: "how good is it to be here?"
In the exercise: cells close to T have a high V(s); cells next to danger zones have a lower one.

The expected return of taking action a in state s and then following the policy. It answers: "how good is this move from this cell?" The best action in a state is the one with the highest Q-value.
In the exercise: each valid cell has four Q-values, one for Up, Down, Left and Right.

A model-free algorithm that learns Q(s, a) from experience. After each step it moves its estimate toward a target built from the immediate reward plus the best discounted Q-value of the next state.
target = r + γ · maxa' Q(s', a')
Q(s,a) ← Q(s,a) + α [ target − Q(s,a) ]
In the exercise: Q-values are updated incrementally after every transition, so the route to T is learned, not programmed manually.

Unsupervised Machine Learning

K-Means Clustering: Concepts

Understanding unsupervised learning, clustering, and how the K-Means algorithm groups music tracks by mood using audio features.

1. What is Unsupervised Learning?

Unsupervised learning is a branch of machine learning in which the model learns patterns directly from data that has no predefined labels or target values. Unlike supervised learning, where the algorithm is trained to predict a known outcome (for example, Logistic Regression predicting whether a session ends in a purchase), unsupervised algorithms explore the data to discover hidden structure on their own, without being told in advance what the "correct" groups are.

2. What is Clustering?

Clustering is one of the most common unsupervised learning tasks. Its goal is to group a set of records into clusters, such that records within the same cluster are more similar to each other than to records in other clusters, according to a distance measure. In this project, clustering is applied to music tracks described by two numerical audio features, Danceability and Energy. Instead of manually labeling each track's mood, the algorithm groups tracks with similar audio characteristics automatically — which can later be interpreted as mood or listening-context categories, such as high-energy party tracks versus calm, low-energy tracks.

3. How K-Means Works

K-Means is one of the most widely used clustering algorithms because it is simple, efficient, and easy to interpret. Given a number of clusters k chosen in advance, it partitions the dataset into k groups by iteratively refining the position of k cluster centers, called centroids.

1
Initialization Choose k initial centroids, either randomly or by manually selecting starting coordinates.
2
Assignment step For every record, compute its Euclidean distance to each centroid and assign it to the nearest one.
3
Update step Recalculate each centroid as the mean coordinates of all records currently assigned to its cluster.
4
Repeat Steps 2 and 3 are repeated for a fixed number of iterations, or until the centroids stop changing (convergence).
d(x, c) = √[(x₁ - c₁)² + (x₂ - c₂)²]
Euclidean distance between a record x and a centroid c
4. The Role of Centroids

Centroids represent the "center" of each cluster in the feature space. They are not necessarily real tracks in the dataset — they are calculated points that summarize the average position of every record assigned to that cluster. Well-separated, stable centroids indicate clear, well-defined clusters, while overlapping centroids may indicate that the chosen number of clusters does not capture distinct groups well.

5. The Role of Iterations

A single pass of assignment and update is rarely enough, because moving the centroids changes which records are closest to each one. K-Means repeats these steps over multiple iterations; with each pass, the centroids typically move less and assignments stabilize, reflected in a decreasing (or stable) within-cluster variance. The algorithm converges once an additional iteration no longer changes cluster membership.

6. Limitations of K-Means
  • The number of clusters k must be chosen in advance.
  • Results can depend on the initial position of the centroids.
  • It assumes clusters are roughly spherical and similar in size.
  • It is sensitive to the scale of the variables, so numerical features with very different ranges usually need to be standardized before clustering.

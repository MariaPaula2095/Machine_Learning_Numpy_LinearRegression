Logistic Regression Concepts

Theoretical foundation of binary classification algorithms and probability modeling.

1. Definition & Justification

Despite its name, Logistic Regression is a supervised classification algorithm. Unlike linear regression which predicts continuous numeric targets, logistic regression estimates the probability ($P$) that a given observation belongs to a specific discrete class.

2. Problem Variables (Domain Definition)
(X) Independent Variable: Time on site (Minutes) — Continuous numerical feature representing user engagement duration on the website.
(Y) Target Variable (Binary): Purchase Decision — Binary categorical outcome ($1 = \text{Yes}$, $0 = \text{No}$) predicting user conversion.
3. Sigmoid Function & Decision Threshold

The algorithm maps continuous real input values into a bounded probability interval $[0, 1]$ using the Sigmoid (logistic) function:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

A Decision Threshold of $0.5$ is applied to convert the predicted probability into a class label:

  • If $P(\text{Purchase}) \ge 0.5 \rightarrow$ Classify as 1 (Purchase = Yes).
  • If $P(\text{Purchase}) < 0.5 \rightarrow$ Classify as 0 (Purchase = No).
4. Linear Regression vs Logistic Regression
Feature Linear Regression Logistic Regression
Target Variable Type Continuous numerical value (e.g., Tons/ha) Binary categorical outcome (e.g., Yes/No)
Curve Geometry Straight line ($y = mx + b$) $S$-shaped Sigmoid curve
Output Range $(-\infty, +\infty)$ Bounded probability $[0, 1]$
Decision Criteria Direct value prediction Probability cutoff via Threshold ($0.5$)
